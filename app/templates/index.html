Academic major project

Does selecting fewer features write a better description?

RetineX describes an image in words, then speaks the description aloud, so that someone who cannot see the image can still know what is in it. It is also an experiment: it builds the same caption model twice, once on all 4096 features from a convolutional network and once on the 512 the Fisher Score ranks highest, and compares them on the same data.

Why a description is the product

An image without a description is a blank to anyone using a screen reader. Alt text solves this when someone writes it, and most images have none. A model that writes a usable sentence about an arbitrary photograph closes part of that gap.

Why fewer features might help

A VGG16 network describes an image with 4096 numbers, and most of them say nothing useful about what the picture is of. The Fisher Score ranks each one by how well it separates images that people described with similar words. Keeping the strongest 512 makes a smaller, faster model. Whether it makes a better one is the question this project exists to answer, and it is not answered yet.

How the comparison will be judged

Both models get the same frozen split, the same vocabulary, the same hyperparameters and the same seeds. Only the image features differ. That is the whole point: if the captions differ, the features are why.

About the data

RetineX uses Flickr8K, 8,091 photographs with five written descriptions each. The copy used here came from a third-party redistribution rather than the original university release, whose download link no longer works. It is very likely the original corpus, repackaged, and this project describes it that way rather than calling it official.

About the output

The Workspace runs the stages that exist: it extracts real features from an image you upload and applies the saved selection. It does not invent a caption to fill the space, and it does not play audio it cannot produce. When those parts are built, the same panels will show real output.
