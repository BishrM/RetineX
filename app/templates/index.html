Visual accessibility

An image that nobody described is a blank.

RetineX reads a photograph and writes what is in it, then reads that description aloud. One upload, one sentence, one voice, for anyone who cannot see the picture in front of them.

Open the Workspace See how it works

Caption generation and narration are still being built. The Workspace runs the part that is finished on an image you choose, and says plainly where the rest will appear.

Most images say nothing

To a screen reader, an image without a description is a gap in the page. Alt text fixes that only when a person sits down and writes it, and most images never get that person. RetineX is built to write it instead, for any photograph, on demand.

A description you can hear

The written sentence is the product and the audio is a second channel, never a replacement. Text stays on screen, selectable and readable, so the description works with the tools people already rely on rather than around them.

How it works

Three steps, in plain terms. The first one runs today; you can watch it happen in the Workspace on an image of your own.

  1. 01

    Look at the image

    {{ status_chip('complete', 'Working') }}

    A convolutional network reads the picture and turns it into a long list of numbers. Most of those numbers say nothing useful, so RetineX keeps only the few hundred that best separate pictures people described in similar words, which makes the next step smaller and faster.

  2. 02

    Write the description

    {{ status_chip('not_implemented', 'In development') }}

    A language model turns that shortlist into one readable sentence about what is in the picture. This is the part still being built, so RetineX does not show a sentence yet rather than showing one it did not produce.

  3. 03

    Say it out loud

    {{ status_chip('not_implemented', 'In development') }}

    The finished description is spoken, with play, pause and stop under your control and the full text always on screen beside it. Nothing ever plays on its own.
